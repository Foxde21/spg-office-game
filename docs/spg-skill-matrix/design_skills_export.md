# Customers Skill Matrix – Design (UI/UX)

## Skills Matrix

### Department: Design

## User research & problem framing
- Junior: helps with collecting insights, works from clear briefs, asks clarifying questions
- Middle: plans lightweight research, synthesizes insights, frames problems and hypotheses
- Senior: drives discovery with PM/BA, validates assumptions, builds strong problem statements
- Expert: sets research standards, mentors teams, scales discovery and insight-sharing

## UX design & interaction
- Junior: creates basic flows and wireframes under supervision
- Middle: designs complete user journeys, considers edge cases and accessibility basics
- Senior: designs complex interactions, balances UX with constraints, improves UX quality bar
- Expert: defines UX principles, drives cross-product consistency, solves ambiguous UX problems

## UI design & visual craft
- Junior: follows existing style guides, produces clean UI screens
- Middle: creates polished UI, improves visual hierarchy and consistency
- Senior: sets visual direction for areas, reviews others, raises craft across product
- Expert: defines visual system direction, drives brand and product coherence

## Design systems
- Junior: uses existing components and tokens correctly
- Middle: contributes components and patterns with guidance
- Senior: evolves design system, defines patterns and governance with engineering
- Expert: owns system strategy, drives adoption and measurably reduces UI debt

## Collaboration & communication
- Junior: communicates design decisions, takes feedback constructively
- Middle: facilitates design reviews, aligns with PM/engineering, manages handoff
- Senior: leads cross-functional alignment, handles conflicts and trade-offs
- Expert: influences stakeholders, improves org processes, mentors and scales practices

## Delivery & ownership
- Junior: supports delivery, prepares assets and specs, follows through on feedback
- Middle: owns a feature end-to-end, ensures quality in implementation
- Senior: owns outcomes for a stream, improves processes and quality gates
- Expert: responsible for design excellence across portfolio and delivery standards
