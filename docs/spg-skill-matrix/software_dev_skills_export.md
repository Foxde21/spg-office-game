Customers Skill Matrix Organizational Chart

Skills matrix

Departments: Software Development

Category / Level: Junior, Middle, Senior, Expert

Professional Experience

Segmental experience of programming languages
- Junior: At least 2 years (3 better) of relevant development experience
- Middle: 5+ years of relevant development experience, incl. Software Design skills, expert knowledge in at least 1 technical area or business domain, able to transfer knowledge and mentor other engineers
- Senior: 8+ years of relevant development experience, incl. Software Design & Architecture skills, expert knowledge in several technical areas & business domains, able to supervise and develop other engineers, able to setup knowledge transfer and drive mentoring process

Software development process knowledge
- Junior: Expected to follow defined software development process under supervision
- Middle: Expected to follow defined software development process with minimal supervision; Intermediate knowledge of SDLC
- Senior: Expected to follow and improve defined processes; Advanced SDLC knowledge; Able to introduce tools and approaches
- Expert: Expert knowledge of SDLC; Able to setup and improve processes; Able to evaluate, define and introduce tools and approaches

Documentation skills
- Junior: Understands and follows project requirements, solution design and technical documentation
- Middle: Creates technical documentation of own code
- Senior: Creates high-quality architecture diagrams, performs functional requirement reviews
- Expert: Creates high-quality system-level documentation, non-functional requirements, audit documentation

Roles played on project
- Junior: Developer
- Middle: Developer / Key Developer
- Senior: Key Developer, Tech Lead, Reviewer, possible Team Lead
- Expert: Team Lead, Technical Lead, Solution Architect, Reviewer, Auditor, Technical mentor

Reliability & Autonomy
- Junior: Works effectively under supervision
- Middle: Implements functionality with minimal supervision; writes unit/integration tests
- Senior: Works without supervision; responsible for subsystems; actively offers improvements; interviews candidates
- Expert: Technical supervisor; responsible for project delivery; introduces architecture/process improvements

Quality
- Junior: Responsible for code quality
- Middle: Creates deliverables in good quality
- Senior: High-quality deliverables; role model
- Expert: Excellent-quality deliverables; responsible for quality of others

Customer relations
- Junior: Not expected to communicate
- Middle: Participates in calls, may visit customers under supervision
- Senior: Good customer skills; visits customers independently
- Expert: Builds trusted relationships; drives discussions

English Level
- Junior: A1–A2
- Middle: B1 Intermediate
- Senior: B2 Upper-Intermediate
- Expert: B2+ Proficient

Responsibilities
- Junior: Writes testable code; creates unit/integration tests
- Middle: Estimates tasks; performs root cause analysis
- Senior: Contributes to SDLC phases; scalable distributed systems; mentoring; DevOps involvement
- Expert: Full project lifecycle; delivers architecture; responsible for operational health

Frameworks and Tools
- Junior: Java 11+, Spring, Hibernate, RDBMS, Git, Docker, etc.
- Middle: Includes NoSQL, queues, Jenkins, Gradle, microservices tools, SonarQube
- Senior: Adds AWS, GCP, Kafka, monitoring, CI/CD, etc.
- Expert: Advanced troubleshooting, reporting, search engines, log analysis

Practices and approaches
- Junior: OOP, Design Patterns, Data Structures, Algorithms
- Middle: SOLID, REST, TDD, BDD, Agile, ACID, Git workflow
- Senior: DDD, microservices, CAP theorem, CI/CD
- Expert: CQRS, architecture principles, system constraints

Domain expertise
- Junior: Not required
- Middle: Basic domain knowledge
- Senior/Expert: To be reviewed
